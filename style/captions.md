# Words on screen

- Use the exact text from the brief, word for word. Do not add claims.
- Sentence case. No exclamation marks, no emoji, no hype words ("revolutionary", "game-changing").
- Numbers only when they come from the repo (stars, version, benchmark in its README), and say where from if unclear.
- Structure:
  1. Hook: repo name + one-line what it is.
  2. What it does: one real image from the repo + one sentence.
  3. Example: a short demo of one practical use (input, steps, output) in a neutral window, labelled
     "Illustrative example". See brand.md "Example demo".
  4. Key points: up to 3 short lines, revealed one at a time.
  5. How it helps me: 1-3 concrete uses for the profile.
  6. Verdict: verdict word + fit score, `github.com/<owner>/<repo>`, and a small line
     "Independent overview · not affiliated with <owner>".
